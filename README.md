## Contenido de las carpetas

En este repositorio se recogen las prácticas realizadas en Diseño y Análisis de Algoritmos durante el curso 2024-2025. Cada carpeta contiene una implementación independiente, junto con sus ficheros de entrada, pruebas y resultados cuando aplica.

### Práctica 1: Análisis de Algoritmos
Estudio experimental de estrategias de multiplicación de matrices. Incluye distintas implementaciones para comparar el comportamiento de la multiplicación por filas, por columnas y otras variantes de análisis de eficiencia.

### Práctica 2: Simulador de máquina RAM
Desarrollo de un simulador de una máquina RAM con su memoria de datos, memoria de programa, cintas de entrada y salida, y el conjunto de instrucciones básicas de la arquitectura.

### Práctica 3: Divide y vencerás
Implementación de varios algoritmos clásicos resueltos con la técnica de divide y vencerás, como búsqueda binaria, torres de Hanoi, mezcla de secuencias y ordenación rápida.

### Práctica 4: Comparador de algoritmos
Resolución del problema del viajante de comercio con distintos enfoques, incluyendo fuerza bruta, programación dinámica y heurísticas, para comparar tiempos y calidad de las soluciones.

### Práctica 5: Recogida de basura
Aplicación de algoritmos sobre un problema de rutas y recogida en grafo, con versiones voraces y metaheurísticas como GRASP y GVNS para mejorar la solución obtenida.

### Práctica 6: Problema de máxima diversidad
Implementación de varias estrategias para el problema de máxima diversidad, entre ellas heurísticas voraces, poda, búsqueda local y GRASP, con datos de prueba y salidas experimentales.

### Otros materiales
Además de las prácticas numeradas, el repositorio conserva una versión independiente del problema de máxima diversidad en la carpeta Maximum-Diversity-Problem-main, junto con resultados y ficheros de entrada propios.
